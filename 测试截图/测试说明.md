## 发现
1. ~~**交卷 POST 无逾时**~~ → **已修复并上线（2026-09-01）**
   原症状：学生2、学生3 的首次交卷 fetch 挂起 >60 秒无回应（GAS 偶发），页面停在「提交中…」且按钮停用，学生无法重试；本测试以重呼 `submitExamData()` 成功送出，且挂起的请求未落地、无重复记录。
   修法：`index.html` 的 `api()` 加 `AbortController`（30 秒逾时），交卷失败一律呼叫 `restoreSubmitBtn()` 解除停用、文字复原「交卷」、强制显示按钮并重绑 onclick。已上传 GitHub Pages 生效。
2. 计分、及格判定（含 50 分边界）、Students 回填、examToken 全部正确。
